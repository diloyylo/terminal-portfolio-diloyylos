# 🌸 Çiçek Açan Terminal Portfolyo 🌿

Dijital dünyada sıradanlıktan sıkılanlar için tarayıcınızın içinde açan, minik sürprizlerle dolu interaktif bir kişisel bahçe (portfolyo) projesi. 🌷

## 🌼 Bahçenin Özellikleri
- Klasik ve solgun CV'ler yerine rengarenk bir komut satırı deneyimi.
- Kullanabileceğiniz komut çiçekleri: `about`, `skills`, `projects`, `contact`, `flower`, `vintage`, `stats`, `clear` 🐝
- Hiçbir karmaşık eklenti istemeyen, saf HTML, CSS ve JavaScript ile yetiştirilmiştir. 🌱

## 🍃 Nasıl Çalıştırılır?
1. Bu küçük bahçeyi (repoyu) bilgisayarınıza indirin.
2. `index.html` dosyasına çift tıklayarak herhangi bir tarayıcıda tomurcuk gibi açmasını sağlayın! 🌻
